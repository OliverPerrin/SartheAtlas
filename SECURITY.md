# Security reporting

Please report vulnerabilities privately through
[GitHub's security advisory form](https://github.com/OliverPerrin/SartheAtlas/security/advisories/new).
Do not put credentials, exploit details or personal data in a public issue.

Include the affected commit, reproduction steps, impact and a minimal example.
The current `main` branch is maintained; fixes are not promised for older
snapshots. This is a volunteer project with no guaranteed response time.

For ordinary bugs and source corrections, use the public issue templates.
